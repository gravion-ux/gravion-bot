# Pro and Support

Maintainer: Priyanshu Kumar Thakur

## Why a paid option exists here

Running a bot for a team needs hosting, uptime and support, which have real running costs. The free version below stays complete for local use; nothing in the free core is removed or crippled to force an upgrade.

## Free (this repository)

- Terminal-first bot workflow in this repository
- Web command deck served by `web/server.py`
- Built-in `/help`, `/pets` and `/status` commands
- Operator-configured bot endpoint or one-shot command

## Paid / supported option

- Managed/hosted deployment setup help
- Priority support for deployment and endpoint configuration
- Team onboarding guidance for the web command deck

Paid features are offered as support, setup help, templates, or a hosted service where stated. They are not hidden gates inside the free code in this repository.
